Luanette playground

A tiny Lua game console for ESP32-S3 boards, running here on the same engine compiled to WebAssembly. Source and docs

Tap or click is A, drag is the d-pad. Keys: arrows, Z for A, X for B, Shift+arrows to tilt.
Ctrl+Enter runs your edits
The API is in docs/api.md. Edits stay in this browser; to put a cart on a board, save it as a .lua file and send it with tools/push.py.
