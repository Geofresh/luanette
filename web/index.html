Luanette playground

A tiny Lua game console for ESP32-S3 boards, running here on the same engine compiled to WebAssembly. Source and docs

Tap or click is A, drag is the d-pad. Keys: arrows, Z for A, X for B, Shift+arrows to tilt. A gamepad works too.

Sprite 0 Draw with spr(0, x, y)

Color 0 is see-through when spr() draws. Keys 0-9 and a-f pick a color; Alt-click or right-click on the sprite picks one up. The editor writes a SPRITES table into the code, each sprite a row at a time.

Sound 8 is empty. Make it with + New sound, or start it from a preset with New from….

Draw notes at the top with the instrument and effect picked above; volume goes in the row below them, and the bottom strip paints the picked instrument and effect. Shift-drag picks notes to copy. Play it in your cart with sfx(8).

No song yet. A song is a list of patterns; each plays up to four of your sounds at once, for as long as the longest of them. Add one with + Pattern.

Patterns play in order. "Loop back" returns to the last "loop start"; "stop" ends the song there. Start it in your cart with music(0); music(-1) stops it.

New here? Your first cart walks through a small game, sounds and a song. The API is in docs/api.md. Edits stay in this browser. Chrome or Edge on a computer can install the firmware and send carts to a board from this page; elsewhere, save a cart as a .lua file and send it with tools/push.py. Your own carts (+ New cart or Open .lua) are kept in this browser; Save .lua keeps a copy anywhere else, and Share link copies a link that opens the cart, its sounds and song too, in anyone's browser (the link is the only copy: nothing is uploaded). Send to board puts the cart in the editor on a board plugged in over USB under its name; an edited example replaces the built-in one until you restore it. tools/push.py does the same from a .lua file.
