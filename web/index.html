Luanette playground

A tiny Lua game console for ESP32-S3 boards, running here on the same engine compiled to WebAssembly. Source and docs

Tap or click is A, drag is the d-pad. Keys: arrows, Z for A, X for B, Shift+arrows to tilt.
Plug in the board over USB. Leave “Erase device” unticked to keep its saves and carts.
Ctrl+Enter runs your edits
The API is in docs/api.md. Edits stay in this browser. Chrome or Edge on a computer can install the firmware and send carts to a board from this page; elsewhere, save a cart as a .lua file and send it with tools/push.py. Your own carts (+ New cart or Open .lua) are kept in this browser; Save .lua keeps a copy anywhere else. Send to board puts the cart in the editor on a board plugged in over USB under its name; an edited example replaces the built-in one until you restore it. tools/push.py does the same from a .lua file.
